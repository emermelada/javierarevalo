## Problem

The SO-101 is an open-source robot arm from the Hugging Face LeRobot
ecosystem. I want mine to do one concrete task: take my phone from my hand and
put it on a wireless charger. Instead of training learned policies, I am
writing the control, inverse kinematics and vision code for it myself.

## Approach

- **The arm.** The follower arm of the SO-101. Every part is 3D printed, and
  the arm is fully assembled.
- **The computer.** A Raspberry Pi 5 running Raspberry Pi OS. The same Pi
  already runs my home automation, so the arm runs as a separate service
  beside it.
- **The code.** Control, inverse kinematics and vision, written by hand in
  Python instead of a trained policy.
